# Мармеладный завод (Gummy Bear Factory)

Совместный проект: полоса препятствий (obby) на фабрике мармеладных медведей с пружинящими желе-платформами и карамельными ловушками.

## Описание проекта

Добро пожаловать на «Мармеладный завод»! Игрокам предстоит пройти красочную полосу препятствий, полную опасностей и сладостей:
- **Пружинящие желе-платформы:** отталкивают игрока вверх при прыжке.
- **Карамельные ловушки:** замедляют или устраняют неосторожных кондитеров.
- **Фабричные конвейеры:** движущиеся ленты с мармеладными мишками.

## Структура проекта (Rojo)

- **`src/ServerScriptService/`** — серверные скрипты и механики игры.
- **`src/ReplicatedStorage/`** — модули, общие скрипты и сетевые события.
- **`src/StarterPlayer/StarterPlayerScripts/`** — клиентские скрипты управления и визуальных эффектов.
- **`src/Workspace/`** — элементы игрового мира и препятствия.

## Использование с Rojo

1. Установите [Rojo](https://rojo.space/) CLI или расширение VS Code.
2. В терминале выполните:
   ```bash
   rojo serve
   ```
3. Откройте Roblox Studio и подключитесь через официальный плагин Rojo.
